01主题切换：从「只换强调色」到「整屏换肤」

旧版三个主题的卡片均为 #FFFFFF、页面底仅差 #FAF6F0 / #F0F7F1（明度差 <3%），肉眼几乎不可辨。新版为每个家族定义了独立的表面色、卡内凹陷色、投影色相与光晕色，页面底与卡片拉开到 15%+ 明度差，卡片真正「浮」起来。

03布局与组件：对齐、栅格、触控与反馈

针对「按钮、文字排版及各类组件布局松散」，逐项收敛到统一规则。

三栏栅格（菜品卡 / 汇总卡 / 菜品库列表统一）

栏位宽度策略说明
缩略图固定 96–128rpx，flex-shrink:0与骨架屏严格同尺寸，加载完成不跳动
信息区flex:1; min-width:0min-width:0 是长菜名省略号生效的前提
操作区flex-shrink:0按钮不被挤压变形
触控底线：所有小按钮视觉高度 ≥68rpx，通过 ::after 伪元素把热区外扩到 ≥88rpx（44px），符合微信与 iOS 的点击热区下限。列表行最小高度 112rpx。

按钮体系

高度档用途变体
96rpx页面主行动（提交、登录）primary 渐变 / secondary 描边 / soft 淡底 / ghost 文字 / danger 危险
84rpx（.btn-md）表单、卡片内操作
68rpx（.btn-sm）列表项右侧

统一 .btn-group 做等分排列，gap:24rpx，不再逐个元素手写 margin。

页面垂直节奏

  • 英雄区：点菜页 / 汇总页顶部加主题色淡染渐变（负边距全出血 + 44rpx 下圆角），首屏有了视觉落点
  • 交替律：卡片（白）→ 淡染条（--accent-wash）→ 胶囊 → 卡片，避免整屏一片白导致层级塌陷
  • 发丝线内缩：分组列表分隔线左缩进 32rpx，与标题文字基线对齐（profile 页）
  • 凹陷收纳：米饭卡内的步进器放进 --color-cream 凹陷块，形成「卡片 > 分区」两级关系

04主题设置页：色卡所见即所得

色卡预览块改为真实还原「页面底 + 卡片 + 强调色按钮」三层结构（旧版只有底色 + 色条），用户在选择前就能看出五个家族的差异；新增「强调色落点」色板说明与「当前生效」标签。
