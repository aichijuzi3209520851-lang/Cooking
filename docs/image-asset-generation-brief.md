# 「今天吃啥」图像素材生成需求单

> 用途：本需求单直接交给生图模型（即梦 / 豆包等）批量产出图片素材，产出后统一放进一个文件夹交付，由开发侧审图、压缩、命名并嵌入小程序。
> 优先级：**第一批（登录页漂浮图标 7 张）为当前需求**；第二批（空状态 + 分类占位图）为可选扩展，想做再做。
> 所有颜色值、构图要求都已对齐项目现有设计系统，**生成时请严格带上下方的「统一风格锚点」**。

## 一、统一风格锚点（每张图的 prompt 末尾都必须拼接这段）

```
极简扁平风格插画，儿童绘本质感，造型圆润饱满无尖角，
暖色调配色：番茄红 #D93A2B、焦糖橙 #F0821E、姜黄 #E6A23C、葱青绿 #2F9E6E、暖棕 #8B5E3C、奶油白 #FDF3E3，
纯色色块填充，允许 1-2 处柔和高光，无描边或极细同色系深色描边，
透明背景，单个主体居中，主体占画面 70-80%，四周留透明安全边，
无文字，无水印，无背景装饰，无投影，可爱、温馨、有食欲
```

**负向提示词（如果工具支持）**：

```
写实照片，3D 渲染，复杂渐变，粗糙线条，文字，水印，签名，背景色块，投影，边框，拼贴，多个主体
```

**风格一致性技巧**：7 张图尽量在**同一次会话/同一个种子**下连续生成；如果工具支持垫图（参考图），先用第一张满意的图作为后续生成的风格参考。

## 四、技术规格（交付硬性要求）

| 项目 | 要求 | 原因 |
|------|------|------|
| 文件格式 | **PNG，透明背景**（第一优先）；若模型不支持透明底，退而求其次用**纯白背景**输出 | 透明底可直接嵌入漂浮层；白底我接入时统一抠图 |
| 生成尺寸 | ≥ 512×512 px，正方形 | 缩到 144px 显示仍清晰（3x 屏） |
| 主体占比 | 图标类 70~80%，分类占位图 ≥85% | 保证缩小后剪影清晰 |
| 阴影 | **不要**在图里画投影 | 漂浮感由页面动效营造，图片带投影会显脏 |
| 文字/水印 | 严格禁止 | 界面不用文字图 |
| 色彩 | 只使用上方色板及其深浅变体 | 保证与界面暖调体系一致 |
| 数量 | 第一批 7 张 | 与现有占位 SVG 一一对应 |

│   ├── rice.png

3. 每张图如果生成了多个候选，可以都放进 `login/_candidates/` 里，我来挑风格最统一的。

## 六、我接入时会做的事（供你了解分工）

1. **审图**：检查透明底、剪影可辨度、色板一致性与七张图风格统一性
2. **规格化**：压缩到嵌入规格（登录漂浮图标 144×144，占位图 208×208），控制每张 <15KB
3. **命名归位**：复制进 `miniprogram/images/login/` 等目录，替换现有占位 SVG
4. **接入**：漂浮层 `<image>` 路径从 `.svg` 换成 `.png`（CSS 零改动），空状态组件增加插画位
5. **回归**：语法/lint/测试 + 深色模式检查（深色下图片透明度由 CSS 变量控制，图片本身无需出深色版）
6. 如风格差异过大或不透明，我会标注具体哪几张需要重新生成
