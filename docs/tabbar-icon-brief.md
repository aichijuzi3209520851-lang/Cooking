# tabBar 导航图标生成需求单

> 用途：替换小程序底部导航（点菜 / 汇总 / 我的）的纯文字样式，改为「图标 + 文字」。
> **格式硬性要求：PNG 透明底**（微信 tabBar 不支持 SVG，勿生成 SVG）。
> 流程：本需求单 → 生图模型出图 → 按第五节目录存放 → 交回开发接入。

---

## 一、统一风格锚点（每张图 prompt 末尾必须拼接）

```
极简图标 glyph，面性风格（实色色块造型，非细线条），
造型圆润饱满、端点圆角，几何感强，细节极少（远看小尺寸清晰），
主体居中占画面 62%，四周透明留白，
纯透明背景，无文字，无水印，无投影，无背景板，无渐变，
扁平插画质感，与美食点餐 App 匹配
```

**负向提示词**：`写实，照片，3D，细线条描边图标，复杂细节，文字，水印，背景色块，投影，渐变，多个主体`

**一致性技巧**：3 个图标务必在**同一次会话**连续生成（或用第一张满意的图垫图），保证笔触与圆润度统一——tabBar 三个图标风格不一致会非常扎眼。

## 三、色彩矩阵（重点：同一造型 × 不同状态配色）

tabBar 图标颜色烤在图片里、不能随主题自动变色，因此每个图标需要 **4 个配色版本**（同一造型重新上色即可，造型不要变）：

| 状态 | 用途 | 颜色（精确值） | 命名后缀 |
|------|------|----------------|----------|
| 普通（未选中） | 全部主题通用 | 暖灰 `#9A938A` | 无后缀，如 `order.png` |
| 选中·温馨暖调 | 浅色暖调主题 | 辣椒红 `#D93A2B` | `-active-warm`，如 `order-active-warm.png` |
| 选中·清新绿意 | 绿色主题 | 葱青绿 `#2F9E6E` | `-active-fresh`，如 `order-active-fresh.png` |
| 选中·静谧夜间 | 深色主题 | 珊瑚红 `#E8564A` | `-active-dark`，如 `order-active-dark.png` |

> 生成技巧：先出 `order.png`（暖灰版）→ 满意后用「同图重新上色为 XX 色」的方式派生其余 11 张，造型像素级一致最理想。

**合计 12 张**（3 图标 × 4 配色）。

## 四、技术规格（硬性）

| 项目 | 要求 | 原因 |
|------|------|------|
| 格式 | **PNG，透明背景**（不支持 SVG） | 微信 tabBar 官方限制 |
| 生成尺寸 | ≥ 512×512px，正方形 | 缩到 81px（3x 屏）仍锐利 |
| 主体占比 | 58%~66%，居中 | tabBar 图标显示仅约 27px，太小会糊、太大会顶边 |
| 文件大小 | 单张 ≤ 40KB | 微信 tabBar 硬限制（缩图后自然满足） |
| 线条/色块 | 面性实色块，**不要细线描边风格** | 27px 下细线会消失 |
| 文字/水印/投影 | 严格禁止 | — |

## 六、开发侧接入方案（供你了解）

1. 审图：4 配色造型一致性、透明底、小尺寸可辨度
2. 规格化：缩至 81×81px，压缩至 <40KB
3. 归位：`miniprogram/images/tabbar/`
4. 接入：`app.json` 配置默认图标路径；`theme.js` 的 `applyTheme` 增加 `wx.setTabBarItem` 调用，主题切换时三张选中态图标随家族联动（温馨→红 / 清新→绿 / 夜间→珊瑚红），未选中态全家族共用暖灰
5. 回归：语法/lint/测试 + 三主题下 tabBar 视觉检查
